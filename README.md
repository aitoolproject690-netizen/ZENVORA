# ZENVORA

A mobile-first, dark creative studio UI built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Current scope

- Home dashboard, projects, create flow, studio workspace, and profile screens
- Local demo project state and search/filter interactions
- Responsive dark UI designed for phone screens

AI generation, accounts, cloud storage, payments, and media export are not connected yet. No API keys are required for this UI demo.
